# Probability Theory for ML

An interactive visual reference for the probability and statistics concepts used in machine learning.

## Topics Covered

- **Foundations** — Random variables, PMF, PDF, CDF, sum & product rules
- **Distributions** — Gaussian, Bernoulli, Binomial, Poisson, Beta (with interactive sliders)
- **Expectation & Variance** — E[X], Var(X), linearity, empirical rule
- **Bayes' Theorem** — Prior → Likelihood → Posterior, base rate fallacy, conjugate priors
- **Information Theory** — Entropy, Cross-Entropy, KL Divergence, Mutual Information
- **Key Theorems** — Law of Large Numbers, Central Limit Theorem, Jensen's Inequality, Markov & Chebyshev
- **MLE vs MAP** — Likelihood, priors, regularisation as Bayesian inference
- **Covariance & Correlation** — Joint variability, covariance matrix, PCA connection

## Tech Stack
       
 - React + TypeScript
 - Vite
 - Canvas API (all charts drawn from scratch, no chart library)

## Run Locally

```bash
cd my-app
npm install
npm run dev
```
